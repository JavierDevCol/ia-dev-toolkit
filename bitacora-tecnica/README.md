## Cómo usar

Cada entrada en la bitácora contiene:
- **Contexto:** Por qué se hizo el trabajo
- **Decisiones técnicas:** Qué se decidió y por qué
- **Evidencia:** Resultados, reportes, capturas
- **Mejoras futuras:** Qué se podría hacer después

---

## Convenciones

- **Formato:** Markdown
- **Ubicación:** `bitacora-tecnica/[nombre-entrada]/`
- **Archivo principal:** `bitacora.md` dentro de cada entrada
- **Evidencia:** Archivos adicionales (reportes, scripts, capturas) en el mismo directorio
