# Solicitud de PR Review (estándar)

**Cuándo usarla:** pedir al equipo que revise un PR sin urgencia ni bloqueo.

```
👀 Solicitud de PR Review - [ID HU / Feature]
Hola equipo, ¿me apoyan con la revisión de este PR por favor?

Contexto: [Breve descripción de lo que hace o soluciona]

Link PR: [Enlace al PR]

HU / Ticket: [Enlace o ID]

Notas: [Ej. Ya pasó pruebas unitarias / Revisar con detalle el archivo X]
¡Gracias de antemano! 🙌
```
