# HU lista para pruebas

**Cuándo usarla:** avisar a QA o al PO que una historia terminó y está desplegada para probar.

```
✅ HU lista para pruebas: [ID y Nombre de la HU]
Hola @[QA / PO], ya finalicé el desarrollo de esta historia y los cambios ya están desplegados en [Ambiente: QA / Staging].

Link HU: [Enlace]

Datos de prueba: [Usuario, rol o payload necesario para probar]

Consideraciones: [Ej. Validar también el flujo X por posible impacto]
Quedo atento a cualquier novedad o feedback.
```
