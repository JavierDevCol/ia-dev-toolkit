# PR Prioritario (bloqueo o hotfix)

**Cuándo usarla:** revisión de PR urgente porque bloquea algo o va a producción.

```
🚨 PR Prioritario - [ID HU / Bug]
Hola @[Mención o equipo], necesito apoyo urgente con este PR ya que bloquea [mencionar qué bloquea o si va a producción].

Cambio: [Resumen en 1 línea]

Link PR: [Enlace]
Quedo atento por si hay comentarios. ¡Gracias!
```
