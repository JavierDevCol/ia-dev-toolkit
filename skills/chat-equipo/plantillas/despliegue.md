# Aviso de despliegue o congelamiento

**Cuándo usarla:** avisar inicio de despliegue (o congelamiento de rama) en un ambiente.

```
🚀 Inicio de despliegue en [Ambiente: QA / UAT / Prod]
Hola equipo, iniciamos el despliegue de [Versión / Feature / HU].

Tiempo estimado: [Ej. 15 minutos]

Impacto: [Ej. Posible intermitencia en el servicio X / Por favor no hacer merge a develop hasta nuevo aviso]
Les confirmo por este mismo hilo apenas finalice.
```
