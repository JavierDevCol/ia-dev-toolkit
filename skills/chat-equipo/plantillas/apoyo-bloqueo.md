# Apoyo con tema o bloqueo

**Cuándo usarla:** pedir ayuda general (tecnología, error, duda) o apoyo ante un bloqueo; no es para revisiones de PR.

```
🆘 Apoyo con [Tema / Tecnología / Error]
Hola equipo, ¿alguien ha trabajado con [mencionar tema] o tiene 5 minutos para revisar un bloqueo?

Objetivo: [Lo que intentas lograr]

Problema: [Error o comportamiento inesperado]

Lo que ya intenté: [Pasos previos para evitar repetir sugerencias]
Si alguien tiene disponibilidad para una llamada rápida, me avisa. ¡Gracias! 🙏
```
