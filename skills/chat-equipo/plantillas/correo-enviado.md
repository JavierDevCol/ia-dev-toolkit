# Aviso de correo enviado

**Cuándo usarla:** confirmar que ya se envió un correo (accesos, reporte, solicitud de aprobación…).

```
✉️ Correo enviado: [Asunto del correo]
Hola @[Persona o equipo], les confirmo que ya envié el correo con [ej. los accesos / el reporte / la solicitud de aprobación] a [Destinatarios principales] (con copia a @[Copiados]).

Resumen: [Puntos clave solicitados o enviados]

Próximo paso: Quedamos a la espera de su respuesta para avanzar con [siguiente tarea o HU].
```
